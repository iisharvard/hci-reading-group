# Harvard HCI Reading Group

Welcome to the Harvard HCI Reading Group! This repository contains our weekly reading group's curated list of research papers, summaries, and discussions.

This repository is set up as a website using Jekyll and GitHub Pages. You can browse the papers, read summaries, and find links to discussions.

## Adding new papers

To add a new paper to the reading group, follow these steps:

1. Fork this repository to your own GitHub account.
2. Clone your forked repository to your local machine.
